Referencing means acknowledging the sources you use. You need both:

- In-text citations
- A reference list

Torrens uses a modified version of APA 7th edition. See the [APA Referencing Tool](https://library.torrens.edu.au/academicskills/apa/tool) for format examples, or [these videos](https://library.torrens.edu.au/academicskills_as/references) for more detail.

To manage your references, Torrens supports Mendeley Reference Manager — see the [Mendeley quick start guide](https://library.torrens.edu.au/mendeley).
