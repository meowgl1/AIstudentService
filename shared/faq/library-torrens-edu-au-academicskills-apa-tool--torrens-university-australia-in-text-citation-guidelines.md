Torrens requires page numbers for all in-text citations. When a page number isn't available, use one of these instead:

- **Paragraph number** — (Author surname, year, para. x), e.g. (Smith, 2025, para. 3)
- **Chapter/section title + paragraph number** — (Author surname, year, section title, para. x), e.g. (Smith, 2020, an overview of nursing practice, para. 2)
- **Page range from an eBook reader** — (Author surname, year, pp. x–y), e.g. (Smith, 2020, pp. 1–5)
