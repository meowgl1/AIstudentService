1. Go to [m365.cloud.microsoft/apps](https://m365.cloud.microsoft/apps) and sign in with your Microsoft 365 student account
2. Select "Install and more", then "Install Microsoft 365 apps"
3. Select "Install Office", then open the downloaded _OfficeSetup.exe_ file

**Tip:** if a User Account Control prompt asks "Do you want to allow this app to make changes to your device?", select "Yes". Full instructions on the [Microsoft site](https://support.microsoft.com/en-au/office/download-and-install-apps-5fa6b61f-70f9-4e93-b15d-16b896a109a3).
