Microsoft requires multi-factor authentication (MFA) for Microsoft 365 resources every 14 days.

- Recommended method: Microsoft Authenticator app on your phone — [follow the setup steps](https://mfastu.torrens.edu.au/). When logging in, select "Don't ask again for 14 days".
- You can add multiple phone numbers so you're not locked out if your primary phone isn't available — [update your security verification settings](https://aka.ms/mfasetup).
- More questions: see the [MFA FAQ](https://mfastu.torrens.edu.au/torrens-mfa/Torrens_MFA_FAQ.pdf).
